# 🛡️ Steam Guard Desktop
Керуй Steam Guard без телефону — один додаток, всі акаунти.

───────────────────────────

## ⚙️ Як працює
Імпортуєш `.maFile` або створюєш новий Guard → додаток генерує 2FA коди в реальному часі → підтверджуєш трейди та маркет прямо з десктопа → все зашифровано AES-256.

───────────────────────────

## 📥 Завантажити та запустити (Для звичайних користувачів)

Не потрібно нічого встановлювати! Програма працює як Portable:

1. Перейдіть на сторінку [Releases](../../releases)
2. Завантажте архів `SteamGuardDesktop-v1.0.0.zip`
3. Розархівуйте його в будь-яку зручну папку
4. Запустіть **`SteamGuardDesktop.exe`**
5. Готово! Можна користуватись.

───────────────────────────

## 📋 Для розробників (Як запустити з коду)

1. Клонуй репозиторій:
```bash
git clone https://github.com/SerhiiLutyk/Steam-Guard-Desktop.git
cd Steam-Guard-Desktop
npm install
npm start
```
2. **Акаунти** → Імпортуй `.maFile` (або перетягни drag & drop)
3. **Guard** → Обери акаунт → код генерується автоматично → клік = копіювати
4. **Логін** → Введи пароль Steam для доступу до підтверджень
5. **Трейди** → Обери акаунт → ✓ прийняти / ✕ відхилити / ▼ деталі
6. **Створити** → Прив'яжи новий Guard без номера телефону
7. Profit 💰

───────────────────────────

## ✨ Фічі
🔐 **2FA коди** — генерація з анімованим таймером 30с, копіювання в 1 клік
📋 **Трейди** — перегляд, прийняття, відхилення з розгортаючими деталями
📦 **Багато акаунтів** — імпорт/експорт `.maFile`, drag & drop
🆕 **Створення Guard** — без номера телефону, тільки email
⚡ **Batch операції** — прийняти/відхилити всі трейди одразу
🔄 **Авто-оновлення** — автоматичне оновлення підтверджень кожні 10с
✅ **Авто-підтвердження** — автоматичне прийняття всіх трейдів
🔒 **AES-256 шифрування** — захист `.maFile` майстер-паролем
⏱️ **Синхронізація часу** — точні коди через синхронізацію зі Steam
🎨 **Сучасний UI** — темна тема, glassmorphism, анімації

───────────────────────────

## 🔐 Безпека
- Всі дані зберігаються **локально** в `%APPDATA%/steam-desktop-auth/`
- Шифрування AES-256-CBC з PBKDF2 (100,000 ітерацій)
- **Нічого** не відправляється на сторонні сервери
- Паролі та секрети **ніколи** не покидають вашу машину
